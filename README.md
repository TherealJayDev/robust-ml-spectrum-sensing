# Robust Machine Learning-Based Spectrum Occupancy Detection
> Final year project submitted for the BEng in Information and Communication Technology at the Federal University of Technology Akure (FUTA).

A simulation-based study comparing feature-based machine learning against
classical energy detection for spectrum occupancy detection (cognitive radio),
with a focus on **robustness** under varying SNR, modulation, and channel
conditions.

## Research question
Not merely *"can ML detect occupied spectrum?"* but the stronger question:
**how robust are feature-based ML spectrum-sensing models when SNR, modulation,
and channel conditions change?**

## Signal model
Binary hypothesis test on each received window:

    H0: y[n] = w[n]                  (channel free, noise only,      label 0)
    H1: y[n] = h[n] * s[n] + w[n]    (channel occupied, signal present, label 1)

## Scope 
- Channels: AWGN, Rayleigh, Rician
- Modulations: sine, BPSK, QPSK, 16-QAM
- SNR range: -20 to +10 dB (step 5 dB)
- Baseline: classical energy detection
- ML models: SVM (RBF), Random Forest, ANN/MLP
- Hybrid features: time-domain + frequency-domain + correlation/eigenvalue
- Experiments: main comparison, feature ablation, one channel-mismatch test
- Metrics: Pd, Pfa, Pm, ROC/AUC, F1, accuracy

## Project structure
    src/        reusable code (signals, channels, dataset, features,
                energy_detector, models, evaluation)
    data/       generated labelled datasets (CSV)
    outputs/    figures, result tables, saved models + scaler
    notebook.ipynb   narrated, step-by-step build and analysis

## Reproducibility
All randomness is seeded. The dataset uses identical noise statistics across
H0 and H1, and SNR/modulation/channel are stored as metadata only (never as
input features) to prevent shortcut learning.

## Environment
See `requirements.txt`. Built with Python, NumPy, SciPy, pandas,
scikit-learn, and Matplotlib.

## Key results

Three ML classifiers (SVM RBF, Random Forest, MLP) trained on 21 engineered features across three families (time-domain, frequency-domain, correlation/eigenvalue) were compared against a classical energy detector at Pfa = 0.1.

- 5-fold cross-validated AUC: SVM 0.9005, RF 0.8981, MLP 0.8998. All three models within 1% of each other.
- ML detectors beat classical energy detection by 10 to 20 percentage points in the -15 to -10 dB transition region. Tie at very high and very low SNR.
- Feature ablation shows the correlation/eigenvalue family (4 features) is the strongest single family, driven by the max-to-min eigenvalue ratio.
- Under channel mismatch (train on AWGN, test on Rayleigh and Rician), all three models degrade at low SNR. Full numbers in `outputs/tables/`.

Main finding: engineered feature representation dominates model choice under channel impairments.

## Reproducing the results

Open `notebook.ipynb` and run cells in order. The seed is fixed (`SEED = 42`), so every run produces identical results.

To skip signal generation and jump straight to feature-level experiments:
- The included `data/features.csv` and `data/metadata.csv` let you start from Phase 5 (energy detector) or Phase 6 (ML training).
- The raw window array (`data/windows.npz`) is regenerated by Phase 3 of the notebook. Takes about a minute.

To fully rerun from scratch:
1. Run Phase 0 and Phase 1 (setup and signal generation).
2. Run Phase 2 and Phase 3 to regenerate the dataset.
3. Run Phase 4 to regenerate features.
4. Run Phase 6 to retrain models.
5. Run Phase 7 to reproduce all comparison results.

## Feature set definitions

| Set | Features | Count |
|-----|----------|-------|
| FS1 (time) | mean_abs, variance, std, rms, energy, skewness, kurtosis, peak, papr | 9 |

| FS3 (corr/eig) | autocorr_peak, cov_trace, max_eigenvalue, eigenvalue_ratio | 4 |
| FS4 (hybrid) | Union of FS1, FS2, FS3 | 21 |
